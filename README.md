## استفاده

```php
use Tavaan\Engine\Pipeline\Pipeline;

// ساده‌ترین حالت: Closure pipes
$response = (new Pipeline())
    ->send($request)
    ->through([
        fn($req, $next) => $next($req . ' [+1]'),
        fn($req, $next) => $next($req . ' [+2]'),
    ])
    ->then(fn($req) => $dispatcher->dispatch($req));

// با Container و Class pipeها
$response = (new Pipeline($container))
    ->send($request)
    ->through([
        TrustProxiesMiddleware::class,
        SecurityHeadersMiddleware::class,
        'auth:web,admin',                  // با پارامتر
    ])
    ->via('handle')
    ->then(fn($request) => $dispatcher->dispatch($request));

// pipe (افزودن یکی)
$pipeline = (new Pipeline())
    ->send($request)
    ->pipe(FirstMiddleware::class)
    ->pipe(fn($r, $next) => $next($r . ' [+x]'));

// thenReturn (destination = identity)
$payload = (new Pipeline())
    ->send($payload)
    ->through([...])
    ->thenReturn();

// terminate (post-stages)
$pipeline->after(fn($passable, $result) => log($result));
$pipeline->terminate($passable, $result);
```

## Middleware Interface

```php
use Tavaan\Engine\Pipeline\Contracts\MiddlewareInterface;

class AuthMiddleware implements MiddlewareInterface
{
    public function handle($passable, \Closure $next, string ...$params): mixed {
        // params = ['web', 'admin'] اگر 'auth:web,admin' بود
        return $next($passable);
    }

    public function terminate(mixed $passable, mixed $result): void {
        // اختیاری — پس از پایان chain
    }
}
```
